VidDrop — برنامج تحميل الفيديوهات (واجهة رسومية لـ yt-dlp)
============================================================

طريقة التشغيل (أول مرة):
1) ثبّت Python 3.10 أو أحدث من python.org
   (مهم: فعّل خيار "Add python.exe to PATH" أثناء التثبيت)
2) شغّل setup.bat ← يثبت المكتبات و Deno (مرة واحدة فقط)
3) شغّل run.bat ← يفتح البرنامج

إذا لم يظهر البرنامج: شغّل run_debug.bat لترى رسالة الخطأ وأرسلها لي.
إذا توقف التحميل من يوتيوب فجأة: شغّل update.bat (يوتيوب يغيّر موقعه باستمرار).

الملفات:
- viddrop.py      الكود الكامل للبرنامج
- requirements.txt المكتبات المطلوبة
- setup.bat / run.bat / run_debug.bat / update.bat

أين تُحفظ الإعدادات وقائمة التحميل؟
  C:\Users\<اسمك>\.viddrop\
مكان التحميل الافتراضي:
  C:\Users\<اسمك>\Downloads\VidDrop\

تحويل البرنامج إلى ملف exe:
1) شغّل setup.bat أولاً (إن لم تفعل)
2) شغّل build_exe.bat وانتظر 1-3 دقائق
3) ستجد البرنامج في المجلد dist\VidDrop.exe
   يمكنك نسخه لأي مكان أو إرساله لأصدقائك؛ لا يحتاج Python.
   (يُفضّل أن يكون Deno مثبتاً على الجهاز ليعمل يوتيوب بكل الجودات)
